Первая лабораторная работа по Python
CLI-приложение на Python с калькулятором выражений и конвертером величин. Интерфейс командной строки реализован с помощью Typer.

Установка
bash
uv sync
Команды
Справка CLI интерфейса

bash
python -m toolkit --help
Калькулятор. Считает выражение внутри "EXPRESSION". Поддерживаются операторы +, -, *, /, скобки и унарные +, -.

bash
python -m toolkit calc "EXPRESSION"
Конвертер. Переводит числовое значение VALUE одной величины в другую. Поддерживаемые единицы:

длина: mm, cm, m, km;

масса: g, kg;

температура: c, f, k.

bash
python -m toolkit convert VALUE --from UNIT --to UNIT
Принятые решения
Калькулятор
Внутри tokenization.py происходит токенизация строки.

Внутри validation.py происходит проверка синтаксиса токенов.

Внутри calculation.py функция to_rpn преобразует выражение в обратную польскую нотацию (алгоритм сортировочной станции Дейкстры).

Внутри calculation.py функция evaluate_rpn вычисляет итоговый результат.

Конвертер
Внутри converter.py описана система величин: UNITS (группа и коэффициент перевода к базовой единице).

Для длины и массы итоговое значение считается по формуле:
value * UNITS[from_unit]['to_base'] / UNITS[to_unit]['to_base']

Для температуры значение сначала переводится в Кельвины, затем — в целевую единицу.

Проверки: неизвестная единица, несовместимые группы, температура ниже абсолютного нуля.

Результат возвращается как float, округлённый до 10 знаков.

Обработка ошибок
Обрабатываются:

пустое выражение;

недопустимый символ;

пропущенный операнд;

два бинарных оператора подряд;

деление на ноль;

неизвестная единица;

несовместимые единицы;

неверное числовое значение.
